# Trip Map

旅行・移動の軌跡を CSV から読み込み、[MapLibre GL JS](https://maplibre.org/) の地図上にルートと地点をアニメーションで可視化するプロジェクトです。
将来的には動画（mp4）への書き出しを想定しています。

## 必要環境

- Node.js 20 以上（推奨: 22）
- npm

## セットアップ

```bash
npm install
```

## 使い方

```bash
npm run dev      # 開発サーバーを起動（http://localhost:5173）
npm run build    # 本番用ビルド（dist/ に出力）
npm run preview  # ビルド結果をローカルで確認
```

### ルートのアニメーション

ページを開くと、ルートが時系列に沿って自動で描かれていきます（1x で全行程が約 20 秒）。
CSV の `timestamp` に比例して進むため、滞在時間が長い区間ほどゆっくり進みます。

画面下部のコントロール:

- **再生 / 一時停止** — アニメーションの開始・停止
- **最初から** — 先頭に戻して再生
- **スライダー** — 任意の位置にシーク（操作すると一時停止）
- **速度** — 0.5x / 1x / 2x / 4x
- **時刻** — 現在位置の日時（ブラウザのタイムゾーンで表示）

### データの差し替え

`data/trip.csv` を編集すると、地図上のルートが変わります。フォーマットは次のとおりです。

| 列名        | 型     | 説明                                   |
| ----------- | ------ | -------------------------------------- |
| `timestamp` | string | ISO 8601 形式の日時（例: `2026-10-01T09:00:00+09:00`） |
| `lat`       | number | 緯度（WGS84）                          |
| `lon`       | number | 経度（WGS84）                          |
| `label`     | string | 地点名（ポップアップに表示）           |

行は時系列順に並べてください。ラベルにカンマは使えません。

## 補足

- ベースマップには MapLibre のデモタイル（`demotiles.maplibre.org`）を使っています。詳細な地図が必要な場合は、別のスタイル URL に差し替えてください。
- 生成した動画ファイル（`*.mp4` など）は `.gitignore` の対象で、リポジトリには含めません。
