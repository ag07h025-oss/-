# Trip Map

旅行・移動の軌跡を CSV から読み込み、[MapLibre GL JS](https://maplibre.org/) の地図上にルートと地点をアニメーションで可視化するプロジェクトです。
アニメーションはそのまま mp4 動画として書き出せます。

## 必要環境

- Node.js 20 以上（推奨: 22）
- npm

## セットアップ

```bash
npm install
```

## 使い方

```bash
npm run dev      # 開発サーバーを起動（http://localhost:5173）
npm run build    # 本番用ビルド（dist/ に出力）
npm run preview  # ビルド結果をローカルで確認
```

### ルートのアニメーション

ページを開くと、ルートが時系列に沿って自動で描かれていきます（1x で全行程が約 20 秒）。
CSV の `timestamp` に比例して進むため、滞在時間が長い区間ほどゆっくり進みます。

画面下部のコントロール:

- **再生 / 一時停止** — アニメーションの開始・停止
- **最初から** — 先頭に戻して再生
- **スライダー** — 任意の位置にシーク（操作すると一時停止）
- **速度** — 0.5x / 1x / 2x / 4x
- **時刻** — 現在位置の日時（ブラウザのタイムゾーンで表示）
- **⬇ mp4** — アニメーションを mp4 で書き出してダウンロード

### mp4 への書き出し

「⬇ mp4」を押すと、現在の地図表示（位置・ズーム・画面サイズ）のまま、アニメーション全体を `trip.mp4` として書き出します。

- 形式: H.264 / 30fps / 画面の実ピクセルサイズ（奇数の場合は 1px 切り詰め）
- 長さ: 選択中の速度に従います（1x で約 20 秒、4x で約 5 秒）
- 動画の左上には現在位置の日時、右下には地図の出典が入ります。画面下のコントロールは動画に入りません
- 1 フレームずつ描画を待って書き出すため、実時間より時間がかかることがあります。書き出し中は地図を操作できません
- [WebCodecs](https://developer.mozilla.org/ja/docs/Web/API/WebCodecs_API) による H.264 エンコードを使います。最新の Chrome / Edge / Safari を推奨します（対応していないブラウザではエラーを表示します）

### データの差し替え

`data/` に置いた CSV は URL の `?trip=<ファイル名>` で切り替えられます（指定がなければ `trip.csv`）。

- `http://localhost:5173/` — 東京の日帰りルート（`data/trip.csv`）
- `http://localhost:5173/?trip=izumo` — 出雲大社周辺の観光ルート（`data/izumo.csv`）

書き出す mp4 のファイル名も `<ファイル名>.mp4` になります。

`data/trip.csv` を編集すると、地図上のルートが変わります。フォーマットは次のとおりです。

| 列名        | 型     | 説明                                   |
| ----------- | ------ | -------------------------------------- |
| `timestamp` | string | ISO 8601 形式の日時（例: `2026-10-01T09:00:00+09:00`） |
| `lat`       | number | 緯度（WGS84）                          |
| `lon`       | number | 経度（WGS84）                          |
| `label`     | string | 地点名（ポップアップに表示）           |

行は時系列順に並べてください。ラベルにカンマは使えません。

## ディレクトリ構成

```
.
├── data/
│   ├── trip.csv    # サンプル: 東京の日帰りルート
│   └── izumo.csv   # サンプル: 出雲大社周辺の観光ルート
├── index.html      # エントリー HTML
└── src/
    ├── main.js       # 地図の初期化・各モジュールの組み立て
    ├── animation.js  # ルートのアニメーション
    ├── basemap.js    # ベースマップ（地理院タイル）の設定
    ├── controls.js   # 再生コントロール UI
    ├── exporter.js   # mp4 書き出し
    ├── csv.js        # CSV パーサー
    └── style.css
```

## 補足

- ベースマップには[国土地理院の地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)（標準地図）を使っています。設定は `src/basemap.js` にあり、URL の `std` を `pale` に変えると淡色地図になります。
  - 地理院タイルは出典の明示が条件です。画面右下に「地理院タイル」を表示し、書き出した動画の右下にも「出典: 国土地理院」を描き込んでいます。消さないでください。
  - 地理院タイルは日本国内向けの地図です。国外のデータでは、詳しい地図が表示されません。
  - 地点名の英数字には MapLibre のデモ用フォント（`demotiles.maplibre.org`）を使います。日本語はブラウザ内蔵のフォントで描画します。
- 生成した動画ファイル（`*.mp4` など）は `.gitignore` の対象で、リポジトリには含めません。
